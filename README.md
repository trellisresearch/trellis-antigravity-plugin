# Trellis Law

> Direct access to the US state trial court system, enabling legal research and insights on cases, verdicts, judges, attorneys, motions, litigation trends, and more - all grounded and sourced from trial court data and documents.

## Requirements

- [Google Antigravity](https://antigravity.google) (desktop app or the `agy` CLI).
- A Trellis account. Sign up at <https://trellis.law>.

## Install

From Antigravity: **Customizations → Marketplace**, search for **Trellis Law**, then **Add**.

From the command line:

```sh
agy plugin install trellis-law
```

Or directly from this repository:

```sh
agy plugin install https://github.com/trellisresearch/trellis-antigravity-plugin
```

## Sign in

The first time Antigravity connects to Trellis, it opens a browser window to sign in with your Trellis account. Antigravity keeps the session, so there is no API key to create, paste or rotate.

## Try it

Ask Antigravity:

- *Summarize the status and recent motion practice in People of the State of New York v. Valve Corporation, NY No. 450952/2026*
- *Give me a profile of lawsuits filed against Tesla in the past 3 years.*
- *How does Judge Timothy B. Taylor in California handle discovery disputes?*

## What this plugin contains

| File | Purpose |
| --- | --- |
| `plugin.json` | Name, version and Marketplace listing. |
| `mcp_config.json` | One remote MCP server, `mcp`, at `https://mcp.trellis.law/gemini`. |

Nothing runs on your machine: no scripts, binaries or local servers. Searches and documents come from the Trellis MCP server over HTTPS, using your own Trellis account and its permissions.

## Data and privacy

Your requests to Trellis tools (search terms, case and document identifiers) are sent to Trellis to answer them. The plugin stores no credentials in this repository or in your project.

See the [Trellis privacy policy](https://trellis.law/privacy-policy).
